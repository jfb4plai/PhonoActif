PhonoActif : logigramme et ressources par étape

État constaté au 2026-11-13. Le schéma part du besoin de l'enseignant et suit le parcours jusqu'au retour d'information. Les valeurs de l'écoute par syllabes sont celles choisies par JF : espace de 500 ms entre les syllabes, dernière syllabe à 75 % de la vitesse.

construit partiel à construire service externe flèche pleine : parcours ; pointillée : option ou retour

Ressources par étape et provenance

INT : interne (JF, Pôle Territorial, code écrit dans le projet). EXT : externe, avec le nom du fournisseur ou de l'auteur. « Non vérifié » signifie que Claude n'a pas pu le confirmer.

5Fabriquer l'audio du pack
  • Transcription phonétique (IPA) de chaque état lettre par lettre.
  • Voix de synthèse belge, appelée avec l'IPA : un fichier par état, par syllabe et par mot entier, à -30 % de vitesse au-delà d'un son.
  • Clé Azure, lue seulement quand JF lance la commande.
  • ffmpeg (local) : rognage des silences, volume commun.
  • INT table son vers IPA et syllabation : code du projet (accord de 99,7 % avec Lexique, en partie ajusté sur le même jeu)
  • EXT Microsoft : Azure Speech, voix fr-BE-CharlineNeural, compte de JF
  • INT JF : lance les générations
  • EXT ffmpeg : outil libre
partiel : 220 fichiers d'états du pack de 100 mots, 112 syllabes + 20 fichiers de mots de 3 syllabes ; bibliothèque complète de 2 780 fichiers non générée ; conditions Microsoft pour la redistribution de l'audio non vérifiées ; quota gratuit non vérifié
